# 错误分类体系

固定枚举：`STATEMENT_MISREAD`、`CONSTRAINT_OMISSION`、`WRONG_ALGORITHM`、`PROOF_GAP`、`CIRCULAR_REASONING`、`HALLUCINATED_CLAIM`、`COMPLEXITY_TLE`、`COMPLEXITY_MLE`、`BOUNDARY_ERROR`、`INTEGER_OVERFLOW`、`STATE_TRANSITION_ERROR`、`IMPLEMENTATION_MISMATCH`、`IO_OR_FORMAT_ERROR`、`COMPILE_ERROR`、`RUNTIME_ERROR`、`RESULT_CORRECT_PROCESS_INVALID`、`UNRESOLVED`。

诊断记录必须附带首错步骤、代码位置、有限证据、置信度、最终结果/过程正确性和修复建议。证据不足时使用 `UNRESOLVED` 并停止盲目修改。
