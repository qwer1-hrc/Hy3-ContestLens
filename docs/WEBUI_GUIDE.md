# WebUI 指南

WebUI 是 REST API 的轻量客户端，不包含独立业务逻辑，也不需要 Node.js。资源页执行校验、授权、发现与 binding；主页中的题目评测入口会打开独立页面，便于同时运行多个题目的工作流；新评测页创建并启动 run；run 页按单调事件游标刷新状态，以可展开时间线显示当前工作和结构化参数，并为初次 Judge 与每轮 Rejudge 保留独立的测试点折叠面板。测试点色块显示 verdict、耗时和峰值内存，展开后可查看退出码、内存上限和首个差异。revision 页显示只增不改的历史；报告页说明可打印产物入口。

报告页按创建时间倒序列出全部运行，展示题目、北京时间、run_id、运行状态与报告入口。点击题目或“查看报告”打开完整评测报告，点击 run_id 查看运行详情。运行失败、取消或尚未产出完整结果时，报告栏显示“空”及原因；失败但已经保留完整评测结果的运行仍可查看报告。点击“刷新列表”获取最新记录。

### 按需报告格式化

打开报告列表或某次完整报告后，页面才会通过 POST 请求启动独立格式化队列。服务启动、解题工作流、普通 REST GET 和状态轮询都不会调用翻译模型。界面统一称为“格式化”，底层仍使用已配置的 Hy3 接口翻译诊断 evidence、修复建议、Critic summary 与逐步骤评审证据、修复计划等叙述字段，不重新解题或改变判定。

翻译使用 `configs/app.toml` 中独立的 `[report_translation]` 配置，默认 `reasoning_effort="low"`、`max_tokens=4096`、`temperature=0.1`、超时 60 秒，每批最多 2 段且合计不超过 2000 字符。求解阶段的推理强度与 token 上限不变；仅模型地址、密钥、模型名和响应协议默认继承 `[hy3]`。可在 `secrets.local.toml` 的 `[report_translation]` 单独覆盖连接参数；同名的 `HY3_REPORT_*` 环境变量作为文件配置缺失时的后备值，例如 `HY3_REPORT_MAX_TOKENS`。优先级为 secrets 配置、app 配置、环境变量、默认值。

模型请求只使用 `t1`、`t2` 等短编号，长哈希只用于本地缓存。每个有效片段立即保存，模型漏项、重复编号或未翻译的片段最多补试 3 次，已成功的片段不再发送。HTTP/JSON 调用本身只尝试一次，补试由报告队列统一管理，避免嵌套整批重试。401/403、非瞬态参数错误及拒答不会反复重试。

`[report_translation].max_concurrency` 默认为 `2`，控制同一报告内部并发执行的批次数；设为 `1` 恢复串行，允许范围为 1–8，也可通过 `HY3_REPORT_MAX_CONCURRENCY` 在文件未配置时设置。每个 WebUI 服务实例仍只调度一份报告，因此多个标签页不会各自扩大并发数，报告优先级和目录顺序不变。并发结果统一加锁合并并原子保存；某批次重试耗尽时不再启动后续批次，但会保存其他已发出批次的有效结果，再将报告标记失败。关闭服务会取消并等待所有子请求，重启后仅续传未完成片段。

遇到 429 时，所有格式化批次共享退避窗口，并参考响应中合法的 `Retry-After` 秒数（最长 30 秒）。并发可以减少多批次的总等待，但不能消除上游自身的断连或限流；限流频繁时可将 `max_concurrency` 降为 `1`。上述并发限制仅针对格式化，不改变求解和图片理解配置。

独立的 `deterministic_judge_verdict=...` 系统判题标记不发送给模型，直接用本地中文模板展示，例如 `deterministic_judge_verdict=WA` 显示为“确定性判题结果：答案错误（WA）”。普通证据仍按原流程翻译与校验，原始标记和评测文件不改写。旧失败缓存可直接点击“重试格式化”继续，已成功的片段仍会复用。

- 从运行详情页点击“查看报告”，当前 run 会进入待处理队首；已经发出的翻译请求先完成，不会中断后重发。
- 从报告列表进入时，按 run 目录名称升序处理已结束且具有完整评测结果的运行。列表本身仍按创建时间倒序展示。
- 页面显示待格式化、排队中、格式化中、已格式化或失败标记。翻译以中文段落、证据列表和 Critic 评审呈现，不再展示诊断 JSON 代码块。
- 报告处理栏、正在格式化的条目、解题启动按钮及当前工作流步骤显示加载动画；完成、失败、取消或连接中断后停止。启用系统“减少动态效果”时使用静态状态提示。
- 缓存及完成标记保存在 `runs/<run_id>/report_translation/zh-CN.json`，仅为内部缓存，原始结果文件保持不变；带有原文指纹和版本，重启后复用。较长内容分批保存，中断后只续传未完成片段。
- 失败不会随刷新自动反复调用模型；在该报告页点击“重试格式化”显式重试。没有完整报告的运行标注为空，不进入队列。
- 更新翻译配置后重启 WebUI 服务，再点击失败报告的“重试格式化”。不需要删除旧缓存：已格式化报告直接复用，部分成功报告只补译未完成片段。
- 详情页顶部和底部均有返回按钮；从当前运行进入时返回运行详情，其余情况返回报告列表。

页面不显示完整标准答案、API Key、宿主绝对路径或 Docker 内部敏感信息。关闭浏览器不会取消后台任务，必须显式点击取消。

## 题面图片理解

独立配置图片模型后，若检测到题面图片或图形，“工作流进度”会展开“等待图片理解选择”步骤。可以选择“使用更精确的图片理解”或“不使用，继续运行”。未配置、超时未选择和识别失败都会继续原流程。成功描述可在步骤中查看，页面刷新不会丢失当前选择。详见 [配置与支持范围](IMAGE_UNDERSTANDING.md)。
