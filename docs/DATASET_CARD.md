# NOIP2018 数据集卡

当前只使用 NOIP2018 提高组 day1/day2：road 10、money 20、track 20、travel 25、game 20、defense 25，共 120 点。来源是用户工作区中的原始竞赛资料。导入器保留源文件只读，复制 `.in` 并把 `.ans` 私有映射为 `.out`，逐文件记录 SHA-256。

公开仓库不应重新分发完整测试数据；`data/private` 已忽略。题面 PDF 绑定记录页段：day1 的 road/money/track 与 day2 的 travel/game/defense 自动按标题起始页切分。

洛谷难度字段当前为 `null`。只有用户提供七档映射并通过枚举校验后才能输出难度分层结论。
